# NocoHR 菜单说明

每个菜单是做什么的、主要给谁用。菜单按权限显示：一个人只看到自己有权打开的页面，下级页面都没有权限的分组整个不显示。下文“主要使用者”以演示案例（启衡精密）的角色分工为准，客户可以在权限设置里调整。

角色简称：**员工**（人人都有）、**主管**（部门负责人，范围只到自己负责的部门）、**HR**（HR 管理员）、**薪酬**（薪酬专员）、**财务**（薪酬审批）、**招聘**（招聘专员）、**培训**（培训专员 / 讲师）、**内审**、**管理员**（系统管理员）。

## 顶栏（每个页面都有）

| 入口         | 做什么                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------ |
| AI 助手      | 在任何页面右侧打开统一的 AI 对话，问制度、查自己的信息、让 AI 员工办事；和“知识问答”是同一个对话 |
| 通知（铃铛） | 未读数；打开是收件箱：提醒、待审批、AI 员工备好的材料                                            |
| 设置         | 只有拥有至少一个设置页的人才看到，见文末“设置”                                                   |
| 头像菜单     | 语言、主题、退出登录                                                                             |

手机上（屏幕窄于 768px）底部另有一排标签：学习 · 考试 · 问答 · 自助 · 我的，员工登录后默认进入“问答”；电脑上默认进入“工作台”。

## 一、人事

| 菜单       | 做什么                                                                                                                     | 主要使用者                     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 工作台     | 登录后的首页。上半部分是 AI 员工已经办完的事（可逐条查看依据），下半部分“等你决定”是需要你拍板的待办                       | 所有人                         |
| 我的档案   | 自己的档案、当前岗位的要求与差距、合同和试用期；可以问“档案助手”自己的问题，也可以在这里连接外部 AI 助手                   | 所有人                         |
| 自助       | 员工自己能办的事集中在一处：请假、补卡、加班、调班、修改个人信息、开具证明等                                               | 员工                           |
| 员工       | 员工档案列表：当前岗位、待补能力；新建、批量导入（先预览再按工号新增或更新）、审核员工提交的信息变更、更正录入错误         | HR，主管（本部门）             |
| 岗位       | 岗位序列与岗位。岗位同时是权限主体：员工按当前岗位获得该岗位被分配的权限                                                   | HR，主管                       |
| 人事异动   | 入职、转正、调岗、晋升、离职，经部门负责人和 HR 两级审批后生效；生效时生成变动影响清单（权限、合同、排班、薪资、学习）     | HR，主管                       |
| 岗位变动   | 部门、岗位、任职状态每一次变化的记录，标明来源（人事异动、飞书同步、导入、更正）和处理结果                                 | HR                             |
| 用工合规   | 每天自动检查劳动合同风险（试用期超期、未签合同、第二次固定期限合同等），只是提示，由 HR 逐条核对                           | HR                             |
| 邮件往来   | 和系统外的人（候选人、客户、离职员工、对账方）的邮件，自动挂到对应单据上；回复由 AI 员工起草，人确认后才发出               | HR，招聘，薪酬（各看各的邮箱） |
| 我的邮箱   | 关联自己的邮箱，自己和候选人的邮件往来显示在系统里；密码只存在邮箱连接里，别人看不到                                       | 招聘、主管等需要收发邮件的人   |
| 合同管理   | 劳动合同的签订、续签、终止和扫描件归档；到期前提醒                                                                         | HR                             |
| 薪资档案   | 员工当前薪资、调薪申请与审批、待建档的新员工                                                                               | 薪酬（财务审批调薪）           |
| 算薪       | 按月算薪：前提检查、导入考勤与其他数据、计算、异常检查、审批、发布工资条                                                   | 薪酬，财务（审批）             |
| 社保公积金 | 参保方案、员工参保、增减员确认、专项附加扣除、年度基数调整                                                                 | 薪酬                           |
| 我的工资条 | 本人已发布的工资条和参保情况，验证身份后才显示金额                                                                         | 员工                           |
| 排班       | 按员工和日期安排班次；每次保存都校验（休息时间、连续夜班、加班上限、持证要求），发布后通知员工；有人请假时 AI 推荐顶班人选 | 主管                           |
| 考勤       | 每日考勤结果、月度汇总、需要跟进的异常；可导入考勤机文件；异常由 AI 先去问本人                                             | 主管，HR                       |
| 假期       | 假期类型与政策、年度余额初始化与人工调整（留痕）、HR 代无账号员工请假                                                      | HR                             |
| 审批       | 等你决定的请假、补卡、加班、调班申请                                                                                       | 主管，HR                       |
| 知识问答   | 向知识助手提问，只根据你有权看的资料作答并注明出处；手机上员工的默认首页                                                   | 所有人                         |
| 知识库     | 制度、操作规范、手册的上传和版本管理；AI 从中检索答案                                                                      | 所有人可读，HR / 培训维护      |
| 组织架构   | 部门树、负责人和在职人数                                                                                                   | 所有人                         |
| 人事报表   | 你可见范围内的人员结构、入离职和流动情况                                                                                   | HR，主管                       |

## 二、招聘

| 菜单     | 做什么                                                                                                                      | 主要使用者             |
| -------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| 用工计划 | 业务量变化（如 ERP 推来的生产计划）时，算出缺多少人，列出加班、借调、招聘等方案和风险，由负责人选一个；选招聘就生成招聘需求 | 主管，HR               |
| 招聘需求 | 部门提出或由用工计划生成的招聘需求，审批通过后开始招聘                                                                      | 主管，招聘             |
| 职位     | 对外发布的职位描述和任职要求；AI 起草，招聘负责人确认后才发布到招聘官网                                                     | 招聘                   |
| 候选人   | 你负责的需求下的投递，按阶段查看；招聘助理读完每份简历给出初筛说明，不给录用建议                                            | 招聘，主管（用人部门） |
| 面试     | 已安排的面试；面试官只看到自己的面试、面试题和去掉联系方式的简历                                                            | 招聘，面试官           |
| 录用     | Offer 经用人经理和薪酬审批后发出，候选人通过专属链接回复；接受后一键转入职单                                                | 招聘，财务（审批）     |
| 招聘报表 | 招聘漏斗、渠道效果、用时等                                                                                                  | 招聘，HR               |

## 三、人才发展

| 菜单     | 做什么                                                                                                  | 主要使用者 |
| -------- | ------------------------------------------------------------------------------------------------------- | ---------- |
| 待我决定 | 人才分析师把发现的问题整理成待决事项（如某能力项问题集中、证书即将到期），附证据，由人决定怎么处理      | 主管，HR   |
| 团队看板 | 团队的持证、能力差距、问题记录和学习进度                                                                | 主管       |
| 找人     | 用一句话描述要找的人（例如“持某证书、某能力达到 3 级”），页面显示解析出的条件，可修改后重查             | 主管，HR   |
| 业务数据 | 来自质量系统、工单、项目等业务系统的记录，按规则匹配到员工和能力项；原始数据只有 HR 可见                | HR         |
| 修订建议 | 作业文件升版后，AI 对课程章节、题目、陪练场景提出的修订建议，以及作答异常题目的改写建议；采纳前内容不变 | 培训，HR   |
| 审计导出 | 供客户审核用的只读导出：个人培训档案、专项培训证明、培训与资格台账、客户审核包；每次导出都记审计日志    | 内审，HR   |
| 人才盘点 | 九宫格：横轴取已发布的考核结果，纵轴取主管的潜力评估；AI 的预放置只作参考                               | HR，主管   |
| 继任计划 | 关键岗位的现任、候选人、准备度和风险；候选人由 AI 推荐，准备度由人选择                                  | HR         |

### 能力体系

| 菜单     | 做什么                                                           | 主要使用者       |
| -------- | ---------------------------------------------------------------- | ---------------- |
| 岗位体系 | 岗位序列、职级和每个岗位的要求（能力项等级、必修课程、必备证书） | HR，所有人可查看 |
| 能力词典 | 能力项及各等级可观察的行为；可导入能力评定结果                   | HR               |

### 学习与培训

| 菜单     | 做什么                                                                             | 主要使用者     |
| -------- | ---------------------------------------------------------------------------------- | -------------- |
| 我的学习 | 指派给自己的课程、学习路径、线下课和 AI 陪练                                       | 所有人         |
| 课程管理 | 课程和章节；AI 可起草，确认发布后才能指派                                          | 培训           |
| 学习任务 | 范围内的学习任务：进度、催办、截止日期                                             | 培训，主管，HR |
| 学习路径 | 按岗位定义的有序步骤（课程、线下实操、陪练、考试），按顺序解锁；新员工入职自动指派 | 培训           |
| 线下班次 | 线下课程排期：报名、扫码签到、补录出勤、导出签到表                                 | 培训           |
| 陪练场景 | AI 陪练扮演的角色和评分要点；确认后才能使用                                        | 培训           |
| 学习计划 | 学习教练针对能力差距起草的计划，人可删改，确认后以本人名义生成学习任务             | 主管，HR       |
| 讲师     | 内部与外部讲师，授课时长、次数、满意度和学员通过率                                 | 培训，HR       |
| 培训评估 | 课后满意度、考试成绩、30 天后主管评价的行为改变                                    | 培训，HR       |
| 译文审核 | AI 起草的英文版课程内容，确认后英文读者才能看到                                    | 培训           |

### 绩效

| 菜单     | 做什么                                                                        | 主要使用者 |
| -------- | ----------------------------------------------------------------------------- | ---------- |
| 我的考核 | 自己的目标、自评和已发布的结果；AI 可起草目标和自评初稿                       | 所有人     |
| 团队考核 | 我要评价的成员：待确认的目标、自评、我的评价和参考分（AI 摆出证据，不给等级） | 主管       |
| 校准     | 按部门和方案对比等级分布与指引，看绩效助理的异常提示，调整等级须填原因        | HR，主管   |
| 考核周期 | 参与名单与排除原因、各阶段截止日、进度看板、催办、AI 初稿采纳统计             | HR         |
| 考核方案 | 维度与权重、等级标准、启用的环节、质量与安全规则、分布指引                    | HR         |

## 四、设置（顶栏“设置”里）

| 菜单                   | 做什么                                                                                            | 主要使用者 |
| ---------------------- | ------------------------------------------------------------------------------------------------- | ---------- |
| 人事设置               | 人事提醒、试用期规则、审批链、必填项等；可以用一句话让人事助理起草修改，确认后才生效              | HR         |
| 组织管理               | 部门树、负责人和成员                                                                              | HR         |
| 组织同步               | 部门和人员与飞书保持一致：同步记录、同步不了的问题、职务对照、卡片发送失败重发                    | HR         |
| 字段管理               | 给员工、候选人等业务表加自定义字段，并决定显示在哪里；升级后保留                                  | HR         |
| 考勤设置               | 班次、考勤规则（按部门）、节假日与调休、轮班模板                                                  | HR         |
| 薪酬设置               | 薪资结构（项目和公式）与算薪规则；只影响尚未提交审批的周期                                        | 薪酬       |
| 招聘设置               | 招聘官网开关、提醒、审批、用工测算参数、新员工回访、邮件与业务系统密钥                            | 招聘，HR   |
| 学习规则               | 学习任务提醒、学习计划有效期、线下签到、视频章节规则                                              | 培训，HR   |
| 持证上岗               | 行业方案开关：证书决定业务系统里的操作权限；列出每个权限集由哪些证书授予；关闭后其他功能照常      | HR         |
| 邮件                   | 各业务邮箱（对账、招聘、审核、人事）的用途、绑定的邮箱和收发规则，离职证明模板确认                | HR         |
| AI 员工任务            | 每位 AI 员工主动做的工作：开关、负责人、运行时间、立即运行、每次的产出和采纳情况                  | HR         |
| AI 入口                | 每类问题由哪位 AI 员工回答、能检索哪些文档，以及飞书机器人                                        | HR         |
| 外部 AI 助手           | 公司的 Claude 工作区等外部助手，用员工本人的个人访问令牌调用 NocoHR，权限与本人一致，调用都有记录 | HR         |
| 授权、用户、AI 员工等  | 平台自带的权限集分配、用户管理、AI 员工和模型配置                                                 | 管理员     |
| 模拟渠道（仅开发环境） | 以通讯录成员身份给机器人发消息，测试 AI 入口；正式部署里没有                                      | 开发       |

## 五、不在菜单里的页面

- **从别的页面点进去的**：员工详情、异动单详情、变动影响清单、工资单明细、课程、考试作答、证书详情、候选人详情等。
- **持证才能操作的业务页面**：设备开工登记、叉车出库登记（制造业行业方案的示例），从证书详情和本人的证书墙进入。
- **不用登录的公开页面**：招聘官网和职位详情、自助约面、AI 面试、Offer 回复、删除个人信息申请、客户审核包下载、离职员工文件下载。都靠专属链接、一次性验证码和有效期保护。

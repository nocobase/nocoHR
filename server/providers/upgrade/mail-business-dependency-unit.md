The reply task fails and no draft is saved, while the poll occurrence reports success. This is an untested proposal, not permission to install another order or evidence that it is sufficient.

## Reproduce

Run only in an owned application checkout without runtime configuration. Each output directory must be new. Failures are expected and must be retained; do not loop to a passing result.

```sh
node tests/acceptance/run-mail-dependency-probe.mjs --order original --phase before --output <owned-output>/normal
node tests/acceptance/run-mail-dependency-probe.mjs --order original --phase late --output <owned-output>/original-late
node tests/acceptance/run-mail-dependency-probe.mjs --order candidate --phase late --output <owned-output>/candidate
```

The first command should pass. The second retains the 30-second failure; the third fails the business-safety assertion despite normal application cleanup. Stop candidate validation there. Candidate patching is limited to the two plugin entries; the common fixture separately enables synthetic recruiting/secrets and registers the test schedule. Neither patch is installed in the shared application.

## Reproduce

Use an owned tracked-source archive of the delivery commit, without deployment configuration or inherited application environment. The scripts refuse common root runtime-config/dotenv files before opening an application. The development supervisor is outside the strict source-server exit-code check.

```sh
verificationRoot="$(mktemp -d)"
verificationEvidence="$(mktemp -d)"
git archive HEAD | tar -x -C "$verificationRoot"
cd "$verificationRoot"
pnpm install --frozen-lockfile --config.strict-dep-builds=true
pnpm typecheck
pnpm build
pnpm exec tsc -p tests/acceptance/tsconfig.json --noEmit
UPGRADE_ACCEPTANCE_OUTPUT="$verificationEvidence/http" pnpm exec tsx tests/acceptance/application-http-lifecycle.ts
UPGRADE_ACCEPTANCE_OUTPUT="$verificationEvidence/recovery" UPGRADE_ACCEPTANCE_BROWSER=false pnpm exec tsx tests/acceptance/upgrade-recovery.ts
pnpm test --maxWorkers=2 --reporter=default --reporter=json --outputFile.json="$verificationEvidence/full-tests.json"
```

The browser flag only reuses already-reviewed screenshots; all service/permission/restore checks still execute. Leave it unset to run the original real browser checks in an environment with Playwright installed. Temporary config, passwords, auth cookies and raw databases must never be attached. The scripts remove their synthetic stores and child services; retain only reviewed logs/results. Delivery evidence includes command/exit logs, HTTP phase events, raw measured windows and preservation hashes. Full-suite temporary-resource cleanup is reported from its actual outcome separately.
